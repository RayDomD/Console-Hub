# The live Stack is app-wide

Cockpit keeps one live Stack across the application and persists it automatically in configuration. Changing Recipe or Workspace never changes that lineup silently. Named Presets may save and restore complete arrangements of slot names, Roles, vendors, models, reasoning effort, and slot instructions; loading one is deliberate and requires confirmation when it would displace active sessions.

Workspace Conventions remain attached to the Workspace rather than being copied into a Preset. Changing a slot's model selects a separate model-specific session instead of replaying history created by another model.
