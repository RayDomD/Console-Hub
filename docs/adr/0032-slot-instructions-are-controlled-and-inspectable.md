# Slot instructions are controlled and inspectable

Every harnessed slot receives four ordered instruction layers: Cockpit's fixed Recipe Contract, the applicable Workspace Conventions, optional Slot Instructions stored with the live Stack or Preset, and a Skill only when the user explicitly attaches one to the run. Cockpit shows the complete effective instructions for every slot before launch with each layer labeled.

Personal global instructions, unrelated installed Skills, extensions, and plugins do not enter automatically. This carries over Fusion Harness's clean-room repeatability without ignoring repository rules or Cockpit's explicit Skill use.
