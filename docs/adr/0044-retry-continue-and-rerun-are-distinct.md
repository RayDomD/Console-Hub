# Retry, Continue, and Rerun are distinct

Retry Slot repeats one failed or stopped turn with the same Recipe, ask, Run Snapshot, and slot; it cannot replace a completed turn. Continue Result starts a new recorded round from a successfully synchronized Synthesize or Coordinate result while retaining participating Sessions during the current app launch. Rerun creates a wholly new run from an earlier Run Record and asks whether to reproduce its original Run Snapshot or use the Workspace's current state.

Direct follow-ups remain ordinary turns in its Session. Debate may add another visible round while two slots survive. Validate retains its own bounded correction loop. Each new round or rerun receives a new Run Record so earlier evidence is immutable.
