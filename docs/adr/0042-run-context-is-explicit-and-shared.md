# Run Context is explicit and shared

An automated run's visible Run Context may contain zero or one Workspace, selected files or folders from the Explorer, zero or one explicitly selected Skill, zero or one cited Reference Packet retrieved from the Vault, and selected outputs or evidence from earlier Run Records. Every item appears as a removable chip before launch; Cockpit never imports ambient files, Skills, or old runs invisibly.

Every slot in a multi-agent Recipe receives the same base Run Context. Coordinate may add narrower task-specific file selections after its held dependency graph is approved, but every addition remains visible in the graph and Run Record.
