# Workspaces have visible writer queues

Write-capable runs queue first-in, first-out per Workspace, freeze their Run Snapshot when the user presses Run, and may be reordered or cancelled before launch. A write-capable run retains its Workspace lease while Held so another writer cannot invalidate the reviewed delegation, dependency graph, or gate.

Quota exhaustion remains a visible terminal slot fault. Cockpit never waits secretly, switches Vendor, or spends another subscription automatically; retry requires the user. The Rest door plate reports Running, Queued, Held, Faulted, or Wants You without entering the Hub. Operating-system notifications, tray behavior, and background startup remain deferred by PRODUCT.md.
