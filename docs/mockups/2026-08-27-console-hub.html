Console
A real terminal you type into — PowerShell or Git Bash, never cmd. Run anything in it. Cockpit opens it, so Cockpit knows its folder. Consoles die with the app.
Card
The console on the canvas. Drag freely, minimize to a strip, expand full-width for real terminal room. Layout persists.
Handoff wire
Drag an arrow between any two consoles, either direction. It persists — part of the saved layout, not a one-time animation.
Brief
What the wire carries — a file on disk written by /codex-brief, with scope, checklist and acceptance criteria. Not scraped scrollback. Both ends read and write it: Claude plans into it, Codex records test evidence back.
Firing the wire
Cockpit types one line into the receiving console and stops. You press enter. Cockpit gains no capability — it saved the typing and got the filename right.
Status rail
One place showing every console's state. Inside the Hub only — never duplicated on the canvas, so it can't disagree with itself.

TierCoversSource of truth
1 · commands npm run build, git, a script, or claude itself — start, end, exit code. Shell prompt markers, injected per console. Same mechanism as folder tracking. exact
2 · agent turns A turn finishing inside a live agent, and “it asked you something”. The agent reports itself — Claude Code Stop hook, Codex notify. exact
3 · mid-run progress “It's 60% done.” Unknowable from outside, and unnecessary. Yellow is enough. not built

Zero footprint — the hook is scoped to Cockpit

Verified against the installed CLIs: claude --settings <file-or-json> loads additional settings; codex -c <key=value> overrides one value. Both layer on top of the real config rather than replacing it.

Inside a Cockpit console

Cockpit set this console up when it opened it.
PS ~\Files\Cockpit> claude
→ runs as claude --settings <cockpit-hook>
Turns are reported. Blue light works; auto-forward has a real signal.

Any other terminal

Windows Terminal, VS Code, anywhere else.
PS ~\Files\Cockpit> claude
→ runs as claude
Unchanged. Cockpit's setup isn't there, so there is nothing to attach.

Nothing is written to .claude or .codex. The hook definition lives in Cockpit's own app data. Delete Cockpit and there is nothing to clean up.

Cost 1. Only catches what you type. Launch claude from a script or by full path and it falls back to Tier 1 silently. Best-effort, not guaranteed.
Cost 2. claude means something slightly different inside the Hub. The console prints one line on open saying what it changed.
Cost 3. Flags are a moving target. Cockpit checks once at startup and says so plainly rather than going dark.

Auto-forward — bounded, and switchable off

Manual is the default: every wire waits for your enter. Per wire, auto-forward can be switched on — and off again at any time. When on, the Stop hook firing is what moves the payload, never a stopwatch. Three limits hold it:

LimitWhy
Hop cap — 3 exchangesTwo agents asking each other to clarify is a loop nothing detects. The cap kills it by construction, then waits for you.
Payload visible on the wireQueued output shows on the arrow before it moves, so a conversation in progress can be watched and stopped.
Never into a console that can writeReview, analysis and planning may auto-forward. Executing a brief against your repo always needs your enter.

RejectedReason
Gateway / swappable brainAnthropic's docs: an active gateway credential replaces the subscription, billed per token. It trades a usage ceiling for a metered bill and doesn't solve running out of Claude. See docs/research/2026-08-27-claude-code-model-harness.md.
Copilot-backed proxiesReverse-engineered; the owner warns automated use can suspend Copilot access.
Machine-wide prompt installChanges every terminal on the machine and survives uninstall. Per-console injection instead.
Editing .claude / .codex configsStrictly worse than the scoped launch flag once --settings and -c were confirmed.
cmd supportCannot emit prompt markers reliably; would ship a console that quietly works worse.
Live cross-console state readsTwo agents reasoning about each other's half-finished state, both wrong, both confident. Handoff wants a clean artifact at a moment in time.
“Needs input” by idle timeoutReplaced by Tier 2. A status that guesses wrong trains you to ignore it.
